# ReAct_Agent

# 🤖 AI Customer Support Agent

A simple AI-powered chatbot built using LangChain, LangGraph, and Google Gemini to handle customer queries like order status, returns, and refunds.

---

## 🚀 Features
- Check order status  
- View delivery details  
- Return & refund policy  
- Process return requests  
- Maintains conversation memory  

---

## ⚙️ Setup

1. Install dependencies:
pip install langchain-google-genai langchain langgraph python-dotenv

2. Create `.env` file:
Gemini_Api_key=your_api_key_here

3. Run:
python main.py

---

## 💬 Example
- Check order ORD-1002  
- What is your return policy?  
- Return my order ORD-1001
